DocQevrilo – Secure Document Management Platform

Live Demo

Project Type: Full Stack Web Application

Role: Full Stack Developer

Technologies: React.js, Node.js, Express.js, MySQL (TiDB Cloud), Backblaze B2, Vercel, Render

React.js Vite Node.js Express.js MySQL (TiDB Cloud) Backblaze B2 Brevo API Vercel Render

About the Project

DocQevrilo is a secure, cloud-based document management platform designed to simplify document storage, organization, sharing, and management. It provides users with a centralized workspace to upload, access, and manage their important files while maintaining privacy and access control.

The platform features separate Admin and User roles, secure authentication, OTP-based password recovery, and cloud-based document storage. Its architecture combines a responsive React frontend with a Node.js backend and a MySQL-compatible cloud database.

Key Features

  • Secure Authentication: User login, registration, and OTP-based password recovery.
  • Role-Based Access Control: Separate Admin and User access with backend-enforced permissions.
  • Document Management: Upload, organize, access, and manage documents.
  • Cloud Storage: Integrated Backblaze B2 for document storage.
  • Admin Dashboard: Centralized user and platform management.
  • Secure Sharing: Controlled document-sharing functionality.
  • Email Integration: Brevo transactional emails for OTP verification and account recovery.
  • Responsive UI: Modern, responsive interface with a red-and-black visual theme.

Technology Stack

  • Frontend: React.js, Vite
  • Backend: Node.js, Express.js
  • Database: MySQL – TiDB Cloud
  • Cloud Storage: Backblaze B2
  • Email Service: Brevo API
  • Frontend Deployment: Vercel
  • Backend Deployment: Render
  • Version Control: Git and GitHub
